# 시연(Demo) 플로우

실제 AI 호출·Trigger 워커·결제 없이 **전체 제품 플로우를 그대로** 시연하기 위한 모드.
켜지면 생성 요청이 지정 이미지(`public/demo/*`)로 즉시 "생성된 척" 완료되며, 그 외
경로(캐릭터 추가·포즈 편집·가입 유도·폴링·갤러리·상태 전이)는 프로덕션과 100% 동일하게 흐른다.

## 켜기 / 끄기 — 숨겨진 어드민 토글 (런타임, 재배포 불필요)

빌드 플래그가 아니라 **요청별 서명 쿠키**로 판정한다. 그래서 **배포된 프로덕션에서도**
숨겨진 어드민 URL 하나로 즉시 켜고 끌 수 있고, 켠 사람의 **브라우저에서만** 시연 모드가
된다(실제 사용자는 전혀 영향 없음). 8시간 뒤 자동 만료.

```bash
# 1) 서버 환경변수에 시크릿 설정 (로컬 .env.local / 배포 대시보드). 비우면 기능 자체 비활성(404).
ADMIN_DEMO_SECRET=<길고 추측 불가한 값>

# 2) 브라우저에서 숨겨진 URL 방문 (프로덕션도 동일)
#    켜기: https://<도메인>/api/admin/demo?key=<ADMIN_DEMO_SECRET>
#    끄기: https://<도메인>/api/admin/demo?key=<ADMIN_DEMO_SECRET>&off=1
```

방문하면 서명 쿠키(`ct_demo`, httpOnly)와 표시용 쿠키(`ct_demo_ui`)가 셋되고 홈으로
리다이렉트되며 `🎬 시연 모드 ON` 토스트가 뜬다. 상단 내비에 `🎬 시연 모드` 배지 +
쿼터 `무제한` 표시. **시크릿을 아는 사람만** 유효 쿠키를 만들 수 있고, 실패/미설정은 전부
`404`로 응답해 기능 존재 자체를 숨긴다. (표시용 쿠키를 위조해도 배지만 뜰 뿐 — 서버는
httpOnly 서명 쿠키로만 실제 동작을 판정하므로 쿼터 우회/데모 큐는 열리지 않는다.)

## 무엇이 실제이고 무엇이 흉내인가

| 구간 | 시연 모드 동작 |
|---|---|
| 캐릭터 추가(업로드 퍼널) | **실제** — IndexedDB(미로그인) / Supabase(로그인) 저장 |
| 3D 포즈 편집·렌더 캡처 | **실제** — WebGL 캔버스 그대로 |
| 가입 유도 → OAuth → 자동 재개 | **실제** — 대기 중 생성 저장 후 로그인, 완료 시 이어서 생성 |
| enqueue → queued → processing → done | **실제 상태기계** — `generations` 행·`job_outbox`·폴링 동일 |
| **AI 생성 결과** | **흉내** — 워커/모델 대신 `demoQueue`가 3.5초 뒤 지정 이미지를 결과로 업로드 |
| 갤러리·결과 중앙 뷰·컨셉 채택 | **실제** — 저장된 결과 이미지 기반 |
| 무료 쿼터(포즈2·컨셉1) | **무제한** — 반복 시연을 위해 제한 해제 |

지정 이미지: 포즈 → `public/demo/pose-a.png`·`pose-b.png`(번갈아), 컨셉아트 → `concept-a.png`.

## 임시 데이터 시드

로그인 계정에 데모 캐릭터 1개 + 갤러리 샘플 2개를 넣어 시작 화면이 비지 않게 한다.

```bash
node --env-file=.env.local scripts/seed-demo.mjs              # 최근 가입 계정
node --env-file=.env.local scripts/seed-demo.mjs you@mail.com # 특정 이메일
node --env-file=.env.local scripts/seed-demo.mjs --reset      # 삭제 후 재시드
```

## 시연 시나리오 (전체 플로우 5분)

1. **미로그인 진입** — `/characters`에서 `새 캐릭터` → 업로드 퍼널(정면/옆면/뒷면 → 컨셉
   설명 → 추가자료 선택)로 캐릭터 추가. "캐릭터 추가 완료" 토스트. → 로그인 없이 브라우저 로컬 저장됨을 설명.
2. **포즈 커스터마이즈** — 홈에서 방금 만든 캐릭터 선택, 3D 에디터로 포즈 조정. 여전히 미로그인.
3. **생성 → 가입 유도** — `이미지 생성` 클릭 → "무료로 생성하려면 로그인" 안내 → Google 로그인.
   (대기 중 생성 요청이 저장되고, 로컬 캐릭터가 계정으로 조용히 이관된다.)
4. **자동 재개 + AI(흉내)** — 로그인 완료 후 자동으로 생성 재개 → `생성 중…`(3.5초) → 지정
   결과 이미지가 **중앙 메인 뷰**로, 직전 포즈는 왼쪽 사이드로. → 상태 전이·폴링이 실제와 같음을 강조.
5. **컨셉아트 경로 + 갤러리** — `새 캐릭터 → 이미지 한 장으로 AI 컨셉아트`로 단일 이미지 →
   컨셉아트(흉내) 생성 → 채택. `전체 갤러리`에서 시드+생성 결과 확인. (쿼터 `무제한`이라 반복 시연 가능.)

## 시연 종료 후

끄기 URL(`/api/admin/demo?key=...&off=1`)을 방문하면 쿠키가 삭제되고 이 브라우저도 실제
파이프라인(Trigger.dev 워커 + 실모델)으로 복귀한다. 방문하지 않아도 8시간 뒤 자동 만료.
완전히 봉인하려면 서버의 `ADMIN_DEMO_SECRET`을 비우면 어드민 URL까지 404가 된다.
시드 데이터는 `scripts/seed-demo.mjs --reset` 또는 앱에서 개별 삭제로 정리.
