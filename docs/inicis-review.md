# KG이니시스 결제 심사 구현 현황

기존 결제는 토스페이먼츠 크레딧 충전이며, 생성 기능의 이용 횟수 차감과 연결되어 있지 않다. `/charge`는 심사 대상 플랜을 표시하고 KG이니시스 PRO 일반 카드결제 테스트를 실행한다. 상품과 가격은 `lib/payments/plans.ts`에서 관리한다.

| 플랜 | 금액 | AI 기능 횟수 |
| --- | ---: | ---: |
| 베이직 | 170,000원 | 50회 |
| 프로 | 320,000원 | 200회 |
| 프리미엄 | 500,000원 | 312회 |

플랜은 월간 기준이지만, 현재는 공개 테스트 상점의 **일회성 결제**이며 실제 정기구독, 자동 갱신, 이용 횟수 지급·차감 및 초기화는 구현되어 있지 않다. 테스트 카드도 실제 승인될 수 있으므로 승인 및 취소 여부를 확인해야 한다. 테스트 주문은 크레딧 0으로 기록하며 승인 처리 시 크레딧을 지급하지 않는다. 통신 오류 등으로 승인 결과가 불명확하면 중복 승인을 시도하지 않고 수동 확인한다.

정기결제 심사 및 운영에는 KG이니시스의 별도 빌링 계약과 가맹점 MID, INILite 키, 빌링 승인용 INIAPI 키가 필요하다. 빌링키의 안전한 보관과 발급 결과 검증, 최초 및 주기별 승인, 중복 결제 방지, 실패 처리, 구독 취소 및 이용 횟수 지급·차감도 별도 구현해야 한다. 실제 가맹점 비밀키는 코드에 넣지 않는다.

참고: [PRO 일반결제](https://manual.inicis.com/pay/pro.html), [빌링 결제](https://manual.inicis.com/pay/bill.html).
